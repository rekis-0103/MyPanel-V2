# Minecraft Assets Attribution

The Minecraft-themed assets in this directory were generated to give MyPanel V2 an immersive, cohesive gaming server identity:

- `hero-landscape.jpg`: Cinematic floating island castle with waterfalls and clouds at sunset.
- `portal-night.jpg`: Aurora borealis night sky over a glowing nether portal and lakeside cabin.
- `redstone-datacenter.jpg`: Isometric Minecraft server rack datacenter built with obsidian, emerald, and glowing redstone repeaters.

All assets are bundled locally by Vite under `'self'` to strictly adhere to the Content Security Policy (CSP).
